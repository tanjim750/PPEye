## Guidelines

The brand identity centers industrial reliability and modern efficiency for field workers and safety officers. The UI should be high-trust, functional, and approachable during safety-critical tasks.

Use a corporate modern foundation with glassmorphism accents: clean Material-inspired layouts, semi-transparent glass cards, and soft ambient shadows. Keep cognitive load low for outdoor and field environments.

Mobile screens should use a single-column stack with strict 20px side padding and 16px vertical rhythm. Larger screens should center content within a maximum width around 448px.

Buttons require at least 48px touch targets. Primary actions should use high-contrast safety blue, 16px radius, and optional icon containers. Status chips should use semantic colors with lightly tinted pill backgrounds.

Cards and list wrappers should use subtle outlines. High-priority widgets can use the glass-card treatment with a soft shadow. Bottom navigation uses a fixed 64px bar with active pill states.
